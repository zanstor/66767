# Bronderbility Music

Сайт битмейкера и лейбла Bronderbility Music. Концепция: **Minimal Distortion**. Чёрный фон, белый моноширинный капслок, единственный акцент — красный `#FF3300`. Волноформы и спектроанализаторы служат главными визуальными элементами, на ховере срабатывают одиночные глитч-эффекты.

Чистые HTML/CSS/JS: без сборки и без зависимостей. Откройте `index.html` или раздайте папку любым статическим сервером:

```bash
npx serve .            # или: python3 -m http.server
```

## Что есть на сайте

- **Hero**: анимированная волноформа текущего бита (красная зона «дисторшна» идёт за плейхедом, клик по ней перематывает трек), плеер с обложкой, таймером и прогрессом.
- **Beat store**: список с миниатюрами волноформ, фильтры по жанрам (Trap / Boom bap / Industrial / Nu-disco), BPM и тональность, добавление в корзину.
- **Signal monitor**: живой спектроанализатор (FFT 2048, 30 Гц–16 кГц, логарифмическая шкала), осциллограф, RMS/пик в dBFS.
- **Sound directions**: 4 карточки жанров, у каждой свой визуализатор (клиппинг 808, вращающаяся пластинка, индустриальный меандр, фигура Лиссажу).
- **Лицензии и саунд-киты**, корзина с выбором лицензии для каждого бита. Кнопка «Request invoice» открывает почтовый клиент с заказом (оплаты на сайте нет).
- **About / Contact**: услуги, форма связи (тоже открывает почтовый клиент), соцсети.
- Мобильная версия: бургер-меню, нижний мини-плеер при прокрутке, горизонтальная карусель лицензий, компактные строки треков. Кнопки управления на экране блокировки через Media Session.

## Звук

Все 13 битов **синтезируются прямо в браузере** (Web Audio API, `assets/js/audio.js`), поэтому сайт работает без аудиофайлов, а анализаторы показывают настоящий сигнал. У каждого жанра свой генератор:

| Жанр | Что звучит |
| --- | --- |
| Trap | дисторшн-808 со слайдами, роллы хэтов, колокольчики / плаки |
| Boom bap / lo-fi | свинг, FM-Rhodes с плаванием плёнки, треск винила |
| Industrial / EBM / synthwave | EBM-бас 16-ми, металлическая перкуссия, пэды с сайдчейном |
| Nu-disco / G-funk | октавный фанк-бас, «качающие» пэды, свистящий G-funk-лид с портаменто |

### Как поставить свои настоящие биты

1. Положите файл в `assets/audio/`, например `assets/audio/machine-heart.mp3`.
2. В `assets/js/data.js` добавьте треку поле `src`:
   ```js
   { id: 'machine-heart', title: 'Machine Heart', ..., src: 'assets/audio/machine-heart.mp3' }
   ```
Плеер, волноформы и анализаторы автоматически переключатся на файл. Треки без `src` продолжат играть синтезированную версию.

## Где менять контент

Всё лежит в `assets/js/data.js`:

- `BRND.config`: почта (**замените `hello@bronderbility.com` на настоящую**), ссылки на соцсети, координаты.
- `BRND.licenses`: уровни лицензий и цены.
- `BRND.tracks`: биты (название, жанр, BPM, тональность, длительность, цена, стиль обложки).
- `BRND.kits`: саунд-киты.

Тексты «About» и заголовки секций находятся в `index.html`. Цвета и шрифты заданы токенами в начале `assets/css/style.css`.

## Структура

```
index.html
favicon.svg
assets/css/style.css   – стили, токены, адаптив
assets/js/data.js      – каталог и настройки
assets/js/util.js      – утилиты: seeded random, scramble-текст, glitch
assets/js/audio.js     – синтез-движок, генераторы жанров, плеер
assets/js/art.js       – генеративные обложки и пики волноформ
assets/js/visuals.js   – canvas-визуалы (волноформы, спектр, осциллограф)
assets/js/app.js       – интерфейс: магазин, корзина, меню, формы, эффекты
```

Учитывается `prefers-reduced-motion`: при этой настройке глитчи, scramble-эффект и случайные артефакты отключаются.
