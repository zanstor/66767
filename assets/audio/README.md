# Сюда кладите mp3-файлы битов

1. Скопируйте файл в эту папку. Имя латиницей, без пробелов: `machine-heart.mp3`.
2. Откройте `assets/js/data.js`, найдите строку нужного бита и перед последней `}` допишите:
   `, src: 'assets/audio/machine-heart.mp3'`
3. Поменяйте в той же строке `duration:` на длину трека в секундах (3:28 → 208).

Подробно — в README.md в корне проекта.
